# SauceDemo E-Commerce SQA & Manual Testing Suite

## 🚀 Overview
This repository contains a comprehensive Manual Software Testing and Quality Assurance (SQA) project built around the SauceDemo e-commerce platform (`https://www.saucedemo.com/`). The project demonstrates a complete Software Testing Life Cycle (STLC) approach, covering functional, boundary, UI/UX, and access control testing across core e-commerce user journeys.

## 🛠️ Tech Stack & Methodologies
- **Target Application:** SauceDemo (Swag Labs Web App)
- **Testing Types:** Manual Functional Testing, UI/UX Validation, Negative Testing, Access Control & Security Testing
- **Artifacts:** Software Test Plan (STP), Structured Test Matrix (Excel/CSV), Defect Tracking Log, Test Execution Summary

## 📂 Key Project Artifacts
- `TEST_PLAN.md`: Defines testing scope, entry/exit criteria, environments, and test strategies.
- `Test-cases.xlsx.csv`: A detailed test case suite covering authentication, catalog sorting, cart state management, and multi-step checkout workflows.
- `DEFECT_LOG.md`: Real-world bug documentation complete with severity ratings, environment details, and step-by-step reproduction instructions.
- `TEST_REPORT.md`: Final execution metrics, pass/fail percentages, and QA sign-off recommendations.
- - `screenshots.md`: contains all proof screenshots for all test.
